01

NLP и обучение моделей

Классификация документов и обращений, NER, семантический поиск, кластеризация и суммаризация. Очистка, нормализация, токенизация, балансировка классов и train / validation / test. Fine-tuning и PEFT / LoRA, подбор гиперпараметров, обработка длинных документов, анализ confusion matrix и ошибок по классам.

02

RAG и семантический поиск

Гибридный поиск BM25 + FAISS, chunking и метаданные, настройка top-k, контекста, порогов релевантности и reranking. Разбор слабых, повторяющихся и противоречивых фрагментов; offline-сравнение поиска и качества ответов на фиксированных наборах запросов.

03

Автономные AI-агенты

Tool calling, маршрутизация запросов и многошаговые сценарии. Управление состоянием и контекстом, проверка результата, лимиты вызовов, защита от повторов и обработка ошибок API. Логирование действий, времени и результатов; разделение оркестрации, поиска, моделей и интеграций.

04

Классическое ML и данные

Классификация и регрессия, baseline на Logistic Regression и Random Forest, сравнение с градиентным бустингом. SQL, pandas и NumPy для подготовки данных; агрегированные, категориальные и временные признаки, PySpark для крупных таблиц. Optuna, кросс-валидация, важность признаков, контроль временных срезов и data leakage.

05

Речевые данные и ASR

Подготовка транскриптов для классификации, извлечения сущностей и суммаризации. Структурирование диалогов, выделение смысловых фрагментов, анализ влияния ошибок ASR на NLP-модели. Исследование диаризации и обработки длинных разговоров.

06

ML Engineering

Полный цикл от данных и baseline до обучения, оценки и интеграции. API на FastAPI, контейнеризация Docker, оптимизация подготовки данных и инференса. Git, code review, документация, type hints, Pydantic, модульные компоненты и конфигурация экспериментов.
