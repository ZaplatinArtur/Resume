ЛИСТ 01 / ПОСТАНОВКА ЗАДАЧИ

Агент в торговой среде

Участвовал в хакатоне по разработке автономного AI-агента для принятия торговых решений в тестовой торговой среде.

Вход
Рыночная информация
Выход
Сигнал → действие → проверка

МОЙ ВКЛАД

  1. Исследовал применение LLM к анализу рыночной информации, формированию сигналов и выбору действий агента.
  2. Рассматривал управление состоянием, учёт результатов предыдущих решений и контроль рисков.
  3. Разбирал связь между прогнозом, действием агента и последствиями для торговой стратегии.
