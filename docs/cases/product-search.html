Мультимодальный поиск товаров по фотографии

Объединил визуальный и текстовый поиск через RRF.

ЛИСТ 01 / ПОСТАНОВКА ЗАДАЧИ

Найти товар по фотографии

Участвовал в разработке системы идентификации товаров по фотографиям этикеток. Объединили Computer Vision, визуальный и текстовый retrieval в одном пайплайне.

Вход
Фотография этикетки
Выход
Ранжированный каталог

МОЙ ВКЛАД

  1. YOLO выделял область товара, SigLIP2 строил визуальные embeddings, VLM извлекала дополнительную текстовую информацию.
  2. RRF объединял результаты поисковых подходов в общий ранжированный список кандидатов.
  3. Работал с каталогом из 2 102 товаров; анализировал ошибки сопоставления и качество визуального поиска.
  4. Проверили 53 известных и 45 неизвестных товаров. На неизвестных обнаружили проблему open-set recognition и необходимость калибровать уверенность и пороги отказа.
