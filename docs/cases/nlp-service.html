01 / Зона проверки

Ключевой факт исчезает при сокращении

↳Объём сокращён примерно на 70% по описанию

02 / Зона проверки

Длинный документ

Что важно проверить

Длина исходного текста усложняет сохранение связного контекста.

Решение / следующий шаг

Исследовалась обработка длинных документов и подготовка входа для моделей.

↳Конкретная стратегия разбиения не заявлена

03 / Граница оценки

Тональность требует отдельной оценки

Что важно проверить

Сокращение объёма текста не измеряет качество анализа тональности.

Решение / следующий шаг

Рассматривать суммаризацию и тональность как отдельные результаты сервиса.

↳Численная оценка тональности не приведена
