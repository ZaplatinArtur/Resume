ЛИСТ 01 / ПОСТАНОВКА ЗАДАЧИ

Весы, которые видят продукт

Разрабатывал прототип весов, который определяет сорт продукта по изображению и рассчитывает стоимость по массе. В основе — visual embeddings и поиск по каталогу вместо фиксированного классификатора.

Вход
Изображение + масса
Выход
Продукт → стоимость

МОЙ ВКЛАД

  1. Работал с 64 сортами фруктов и овощей и визуальным encoder с 256-мерным векторным представлением.
  2. Реализовал поиск ближайших товаров в PostgreSQL / pgvector по косинусному расстоянию; подготовил каталог embeddings и train / test для offline-оценки.
  3. Интегрировал MediaPipe для определения рук в кадре; экспериментировал с YOLO и DINOv2.
  4. Разработал FastAPI-сервис: изображение и масса → распознавание → цена за килограмм → итоговая стоимость.
