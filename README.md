# Портфолио Артура Заплатина

Статический сайт для GitHub Pages в образе чертёжного стола сверху: девять отдельных папок с корешками, вложенными чертежами, образцами и заметками об экспериментах. Есть фильтры, анимированные сцены, разборы в раскрытой папке и проверочный стенд. У каждого проекта также есть отдельная HTML-страница, которая открывается без JavaScript.

## Где редактировать

- `templates/index.html` — структура и тексты главной страницы.
- `docs/resume-data.json` — новые проекты, стек и практические навыки.
- `docs/project-content/` — подробные описания двух исходных RAG-проектов.
- `project_art.py` и `site_builder.py` — тематические рисунки и генерация страниц.
- `desk_art.py` — чертёжные инструменты, схема на первом экране, образцы и заметки для всех девяти проектов.
- `drafting_tools.py` — линейка, угольник, карандаш и циркуль для композиции стола сверху; листы вращаются только в плоскости стола.
- `docs/styles.css` — базовое оформление, разборы и анимации; `docs/desk.css` — композиция и стиль чертёжного стола.
- `docs/app.js` — фильтры, диалоги, вкладки, сравнение метрик, демонстрации и управление движением.
- `project_sheets.py` — четыре листа для каждой папки, узлы схем и разбор ошибок. Содержимое основано на резюме и исходных описаниях; ограничения отделены от измеренных результатов.
- `docs/folders.css` и `docs/folders.js` — оформление листов и интерактивные выноски. Работают в диалоге и на отдельных страницах. Вкладки и узлы поддерживают стрелки, Home и End; без JavaScript все листы и выноски остаются доступны.

В проверочном стенде поиск показывает опубликованные в резюме метрики Уральского RAG на 25 вопросах. Визуальный каталог и суммаризация — явно обозначенные подготовленные примеры, без запуска модели или обращений к API. Декоративные образцы в карточках не выдаются за реальные ответы моделей.

После правки шаблона, данных, графики, стилей или поведения запустите `python site_builder.py` из папки репозитория. Генератор обновляет главную, девять страниц в `docs/cases/` и версии ресурсов для обновления браузерного кэша. Используются только стандартные библиотеки Python.

Сайт публикуется из `docs/`. Анимации учитывают настройку уменьшения движения и останавливаются кнопкой на главной; сцены в карточках работают только в области просмотра.

Генератор PDF в родительской папке продолжает использовать тот же файл данных и запускает сборку сайта через совместимый файл `sync_resume_site.py`.
